PRJ-01

Student Information System

Academic project · Spring Boot + MySQL

The Problem

Managing student records by hand (or in scattered spreadsheets) is slow and error-prone — admin staff need a simple, reliable way to add, look up, update, and remove student data.

My Approach

Built a backend REST API in Spring Boot that handles all CRUD (Create, Read, Update, Delete) operations on student records, backed by a MySQL database for persistent storage. A lightweight HTML/Bootstrap front end lets a user interact with the system without touching the database directly.

What It Does

  • Add, view, edit, and delete student records through REST endpoints
  • Stores and retrieves data reliably from a MySQL database
  • Simple, clean interface for day-to-day data entry and reporting

What It Demonstrates

  • Backend API design and REST principles with Spring Boot
  • Relational database design and querying with MySQL
  • End-to-end thinking from database schema to user-facing form

PRJ-03

Smart Railway Track Monitoring & Accident Prevention

Final-year engineering project · Batch 10 · 4-member team · Guided by Mrs. P. Ajitha, B.Tech., M.E.

The Problem

Railway safety depends heavily on accurate track monitoring. A wrong track switch, faulty signal, or misaligned rail can lead to severe accidents — and manual/sensor-only monitoring systems can be costly or slow to flag these issues.

The Aim

Design an intelligent railway track monitoring system using image processing and deep learning (YOLOv8) to detect track-switching errors and confirm safe train movement in real time.

My Role

Worked on the computer-vision pipeline — frame preprocessing, edge/line detection for track alignment, and integrating the obstacle-detection model into the live video pipeline.

How It Works

  • Captures live video of the track using OpenCV
  • Preprocesses each frame (grayscale + Gaussian blur) and applies Canny edge detection
  • Uses Hough Line Transform to identify rail lines and compute track gauge/position
  • Tracks rail position frame-to-frame to detect switching between Main Line and Loop Line
  • Runs a YOLO-based deep learning model (via TensorFlow/Keras) to flag obstacles or people on the track in real time
  • Displays live status overlay — e.g. "On Track 1" / "Switched to Track 2" / "Obstacle Detected"
